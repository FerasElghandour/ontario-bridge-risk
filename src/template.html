Which Ontario provincial bridges to fix first

An analysis of every provincially owned bridge and culvert in Ontario's open bridge-condition data. It ranks where repair money does the most good, shows where the backlog is building up, and tests whether past deterioration predicts future condition.

The Bridge Condition Index (BCI) measures state of repair from 0 to 100. MTO treats 70+ as good, 60–70 as fair (the ideal time to repair) and under 60 as poor (work usually within a year). BCI is not a safety rating. The latest public file covers inspections to the end of 2020; current conditions will differ.
